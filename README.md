# 火柴人桌宠

> GitHub 仓库：`Da0Mine/Desktop-Stickman`

一个跑在你桌面上的白色火柴人。它通过实时屏幕感知，在桌面元素（窗口边缘、任务栏、图标）上行走、跳跃、贴墙、冲刺，像一位真正的桌面伙伴。

> 纯 Python + PyQt5 实现，火柴人由程序化矢量绘制，无需任何图片素材。

## ✨ 特性

- **桌面物理宠物**：无边框、置顶、透明背景、鼠标穿透，火柴人就“站”在你的桌面上，不挡操作。
- **屏幕感知碰撞**：每帧截取周围区域，按灰度梯度检测地面 / 墙 / 天花板，让火柴人能在窗口、任务栏、图标上落足。
- **流畅动作系统**
  - 重力、跳跃（含 0.18s 土狼时间，离地瞬间仍可起跳）
  - 贴墙自动下滑 + 墙跳
  - 双击方向键冲刺，冲刺过程中无视障碍穿墙
  - 着地时按住 `↓` 进入下蹲
  - 程序化骨骼正运动学：跑步、跳跃、贴墙、下蹲、冲刺均为平滑矢量动画，并带呼吸起伏
- **全局键盘控制**：优先使用 Win32 低级键盘钩子（`WH_KEYBOARD_LL`）接收按键，不依赖窗口焦点；钩子不可用时自动回退 pynput，且单源去重避免连发竞态。
- **实时调参面板（`F2`）**：14 项物理 / 渲染参数（重力、速度、跳跃力度、扫描半径、火柴人大小等），滑条 + 数值框，改动即时生效；支持保存、更新、管理多套配置存档。
- **姿势编辑器**：拖拽关节点即可设计火柴人动作并保存为 `poses.json`；整套动作（静止 / 跑步 / 贴墙 / 下蹲 / 跳跃 / 冲刺）可存档、载入、一键恢复默认。
- **系统托盘**：右下角托盘图标，左键开关设置面板，右键菜单退出。

## 🎮 操作说明

| 按键 | 功能 |
| --- | --- |
| `←` `→` / `A` `D` | 左右移动 |
| `↑` / `W` / `空格` | 跳跃（贴墙时自动变为墙跳） |
| `↓` / `S` | 空中快速下落；着地时按住进入下蹲 |
| 双击 `←` `→` `↑` `↓` | 向该方向冲刺（冲刺中穿墙） |
| `F2` | 打开 / 关闭设置面板 |
| `ESC` | 退出程序 |

启动后火柴人会自动出现在屏幕中央，直接操控即可。

## 📦 安装

### 方式一：下载安装包（推荐）

前往仓库的 **Releases** 页下载 `stickman1.0.exe`，双击即可运行，无需安装 Python 环境。

> 首次运行会在 exe 同目录生成 `poses.json`、`cfg_saved.txt` 等用户数据文件，之后的编辑都保存在该目录，重启不丢失。

### 方式二：从源码运行

```bash
# 需要 Python 3.10+
pip install -r requirements.txt
python stickman_pet.py
```

打开姿势编辑器（拖拽编辑动作）：

```bash
python pose_editor.py
```

## 🛠 构建

使用 PyInstaller 打包为单文件 exe：

```bash
pyinstaller --noconsole --onefile --icon stickman.ico \
  --add-data "poses.json;." \
  stickman_pet.py
```

打包后的 exe 首次启动会把内置的 `poses.json` 等数据文件复制到 exe 同目录，之后的用户编辑均保存在该目录（不会因重启而丢失）。

## 🧩 工作原理（简述）

1. **渲染**：在透明置顶窗口上以矢量方式绘制白色火柴人（深色描边 + 白色填充，保证浅色背景也清晰可见）。碰撞箱按精灵实际轮廓生成——身体能穿过的地方就能过。
2. **屏幕感知**：用 `mss` 截取火柴人周围区域，按灰度梯度检测水平 / 垂直边缘，结合阈值与连续长度判定地面、墙、天花板。
3. **物理**：经典欧拉积分重力 + 分轴逐步碰撞检测，含土狼时间、贴墙去抖、墙跳斜抛、冲刺残影等手感细节。
4. **输入**：优先安装 Win32 全局键盘钩子，单源 + 集合去重对连发天然幂等；失败时回退 pynput。

## 📁 项目结构

```
stickman_pet.py      # 主程序：渲染 / 物理 / 屏幕感知 / 输入 / 设置面板
pose_editor.py       # 姿势编辑器：拖拽关节点编辑动作并保存 poses.json
poses.json           # 默认动作数据（跑步 / 贴墙 / 下蹲 / 跳跃 / 冲刺）
stickman.ico         # 应用图标
启动火柴人.bat        # 源码运行启动脚本
dist/                # 本地构建产物（安装包通过 GitHub Releases 发布，不入库）
requirements.txt     # Python 依赖
```
